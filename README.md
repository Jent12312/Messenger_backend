# Messenger Backend (C++ / Drogon / PostgreSQL / Redis)

Высокопроизводительный асинхронный бэкенд для мессенджера корпоративного уровня. Построен на базе компилируемого веб-фреймворка **Drogon (C++20)**, СУБД **PostgreSQL** для хранения реляционных данных и **Redis** для быстрого управления сессиями пользователей.

## 🛠 Технологический стек

*   **Язык программирования:** C++20 (G++ 12+)
*   **Фреймворк:** Drogon (Event-driven, non-blocking I/O на базе `epoll`)
*   **База данных:** PostgreSQL 15
*   **Кэш / Сессии:** Redis 7
*   **Безопасность:** OpenSSL 3.0 (EVP API для бесшовного хэширования SHA-256)
*   **Контейнеризация:** Docker, Docker Compose

## 🧠 Ключевые архитектурные решения

1.  **Асинхронность на Coroutines (C++20):** 
    Вместо сложного и запутанного кода на колбэках (Callback Hell) в проекте используются современные сорутины C++ (`co_await` / `co_return`). Это делает код линейным и легко читаемым, сохраняя феноменальную скорость неблокирующего ввода-вывода.
2.  **Скользящие сессии (Sliding Expiration):**
    Сессии пользователей хранятся в Redis с базовым временем жизни (TTL) 30 дней. При каждом обращении авторизованного пользователя к защищенным эндпоинтам время жизни сессии автоматически продлевается еще на 30 дней асинхронной командой `EXPIRE`, минимизируя нагрузку на Postgres.
3.  **Автогенерация уникальных кодов:**
    При регистрации каждому пользователю присваивается уникальный буквенно-цифровой код формата `USR-XXXX-XXXX` для быстрого поиска и добавления в контакты.
4.  **Docker-First подход:**
    Проект собирается внутри официального легковесного образа `drogonframework/drogon`. Инициализация БД происходит автоматически при первом запуске контейнера через SQL-миграцию.
