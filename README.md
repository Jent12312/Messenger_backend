# 🚀 High-Performance Messenger Backend (C++ / Drogon)

Энтерпрайз-бэкенд для мессенджера, разработанный на C++20 с использованием фреймворка [Drogon](https://github.com/drogonframework/drogon) (самого быстрого веб-фреймворка по версии TechEmpower). 

Архитектура построена на принципах **асинхронности (Non-blocking I/O)** и **сорутинах (C++20 Coroutines)**, что обеспечивает феноменальную скорость обработки запросов при минимальном потреблении оперативной памяти.

## 🛠 Технологический стек

- **Язык**: C++20
- **Веб-фреймворк**: Drogon (Coroutines, Thread Pool, Event-driven)
- **База данных**: PostgreSQL 15 (Асинхронный драйвер, Connection Pool)
- **Кэш / Сессии**: Redis 7 (Асинхронный доступ, Sliding Expiration)
- **Криптография**: OpenSSL 3.0 (EVP API для хэширования SHA-256 и безопасной генерации токенов)
- **Инфраструктура**: Docker, Docker Compose (готово для деплоя через Coolify / CI/CD)

## ✨ Реализованный функционал

- **Health Check**: Асинхронная проверка доступности базы данных без блокировки потоков.
- **Безопасная Регистрация**: 
  - Хэширование паролей.
  - Автогенерация уникальных кодов пользователей (формат `USR-XXXX-XXXX`).
  - Защита от дублей логинов на уровне БД.
- **Авторизация и Сессии**:
  - Генерация криптографически стойких токенов сессий (64 символа).
  - Хранение сессий в Redis.
  - Механизм *Sliding Expiration* (автопродление жизни токена на 30 дней при любой активности).
- **Middleware (HttpFilter)**: Защита эндпоинтов от неавторизованного доступа (проверка `Bearer` токена в Redis на лету).
- **Профили**: Получение данных профиля пользователя (с передачей контекста `user_id` между слоями).

## 🚀 Как запустить локально

Для запуска проекта вам потребуется только установленный **Docker** и **Docker Compose**. Вам не нужно устанавливать C++ компиляторы или базы данных на свой компьютер.

1. **Клонируйте репозиторий**:
   ```bash
   git clone <url_вашего_репозитория>
   cd messenger-backend
   ```

2. **Запустите контейнеры**:
   ```bash
   docker-compose up -d --build
   ```
   *Docker автоматически поднимет PostgreSQL, выполнит SQL-скрипты, поднимет Redis, скомпилирует C++ код и запустит сервер на порту 8080. Благодаря встроенным Healthchecks, бэкенд запустится только после полной готовности базы данных.*

3. **Проверьте статус сервера**:
   Откройте в браузере `http://localhost:8080/api/v1/health`. Вы должны увидеть:
   ```json
   {
       "db_connection": "success",
       "status": "ok"
   }
   ```

## 📡 Текущее API

Все запросы и ответы используют формат `application/json`.

| Метод | Эндпоинт | Описание | Защищен |
| :--- | :--- | :--- | :---: |
| `GET` | `/api/v1/health` | Проверка связи с БД | ❌ |
| `POST` | `/api/v1/auth/register` | Регистрация пользователя | ❌ |
| `POST` | `/api/v1/auth/login` | Вход (возвращает токен сессии) | ❌ |
| `GET` | `/api/v1/user/profile` | Получить свой профиль | 🔐 |

### 🔐 Использование авторизации
Для доступа к защищенным эндпоинтам (например, `/profile`), передавайте токен, полученный при логине, в HTTP-заголовках:
```http
Authorization: Bearer <ваш_токен_из_redis>
```
