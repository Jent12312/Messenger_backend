# 🚀 High-Performance Messenger Backend (C++ / Drogon)

Энтерпрайз-бэкенд для мессенджера, разработанный на C++20 с использованием фреймворка [Drogon](https://github.com/drogonframework/drogon) (одного из самых быстрых веб-фреймворков по версии TechEmpower). 

Архитектура построена на принципах **асинхронности (Non-blocking I/O)** и **сорутинах (C++20 Coroutines)**, что обеспечивает высокую скорость обработки запросов при минимальном потреблении оперативной памяти.

## 🛠 Технологический стек

- **Язык**: C++20
- **Веб-фреймворк**: Drogon (Coroutines, Thread Pool, Event-driven)
- **База данных**: PostgreSQL 15 (Асинхронный драйвер, Connection Pool, расширение **`pg_trgm`** для нечеткого поиска)
- **Кэш / Сессии**: Redis 7 (Асинхронный доступ, Sliding Expiration)
- **Криптография**: OpenSSL 3.0 (EVP API для хэширования SHA-256 и безопасной генерации токенов)
- **Инфраструктура**: Docker, Docker Compose (готово для деплоя через Coolify / CI/CD)

## ✨ Реализованный функционал

- **Health Check**: Асинхронная проверка доступности базы данных без блокировки потоков.
- **Безопасная Регистрация**: 
  - Хэширование паролей на уровне OpenSSL 3.0 EVP.
  - Автогенерация уникальных кодов пользователей (формат `USR-XXXX-XXXX`).
  - Защита от дублей логинов на уровне БД.
- **Авторизация и Сессии**:
  - Генерация криптографически стойких токенов сессий (64 символа).
  - Хранение сессий в Redis.
  - Механизм *Sliding Expiration* (автопродление жизни токена на 30 дней при любой активности).
- **Middleware (HttpFilter)**: Защита эндпоинтов от неавторизованного доступа (проверка `Bearer` токена в Redis на лету).
- **Профили**: Получение данных профиля пользователя (с передачей контекста `user_id` между слоями).
- **Поиск Пользователей**:
  - Быстрый нечеткий (fuzzy) поиск по юзернейму или имени/фамилии с использованием GIN-индексов и триграмм в PostgreSQL.
  - Точный моментальный поиск по уникальному коду пользователя (формат `USR-XXXX-XXXX`).
  - Ограничение выдачи результатов (Limit) для снижения нагрузки на сеть.

## 📂 Структура проекта

```text
├── db/
│   └── init.sql                 # SQL-миграции (схема БД, GIN-индексы, pg_trgm)
├── src/
│   ├── controllers/             # HTTP REST Контроллеры (C++20 Coroutines)
│   ├── filters/                 # Middleware (AuthFilter)
│   ├── utils/                   # Утилиты (CryptoUtils для хэшей и генерации)
│   └── main.cc                  # Точка входа сервера
├── CMakeLists.txt               # Конфигурация сборки C++
├── config.json                  # Конфигурация Drogon (Порты, доступы к БД и Redis)
├── docker-compose.yml           # Оркестрация контейнеров (Backend, Postgres, Redis)
└── Dockerfile                   # Оптимизированный образ на базе drogonframework/drogon
```

## 📡 Текущее API

Все запросы и ответы используют формат `application/json`.

| Метод | Эндпоинт | Описание | Защищен |
| :--- | :--- | :--- | :---: |
| `GET` | `/api/v1/health` | Проверка связи с БД | ❌ |
| `POST` | `/api/v1/auth/register` | Регистрация пользователя | ❌ |
| `POST` | `/api/v1/auth/login` | Вход (возвращает токен сессии) | ❌ |
| `GET` | `/api/v1/user/profile` | Получить свой профиль | 🔐 |
| `GET` | `/api/v1/user/search?q=...` | Поиск пользователей (по нику, ФИО или коду) | 🔐 |


Для доступа к защищенным эндпоинтам (например, `/profile`), передается токен, полученный при логине
